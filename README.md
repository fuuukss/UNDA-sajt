# UNDA sajt

Sajt gradimo postepeno i svaki korak odobravamo pre nastavka.

## Dogovoreni način rada

1. Napravimo jedan mali deo sajta.
2. Pregledamo ga lokalno.
3. Zajedno unosimo izmene.
4. Kada je deo odobren, pravimo Git commit.
5. Tek tada prelazimo na sledeći deo.

## Faze

1. Struktura i vizuelni pravac
2. Zaglavlje i prvi ekran
3. Usluge
4. Izdvojene reference
5. Sve reference
6. Kontakt i forma
7. Mobilni prikaz i završna dorada
8. ZIP paket i objavljivanje

Prethodna kompletna proba sačuvana je u Git grani `first-draft`.
